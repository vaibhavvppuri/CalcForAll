# Public Version 1

This repository snapshot is the initial CalcForAll development preview, internally `1.0.0-preview`.
The original tested source commit is `ceca6bd3e1511b6b872ad0ca245ef443e487ca20`.

Download the Android APK, optional local API, complete source and historical verification evidence from [Version 1 releases](https://github.com/vaibhavvppuri/CalcForAll/releases/tag/v1).

The public source archive and this tree remove one internal local path in a design-handoff document. Application code, dependencies, build inputs and licenses remain unchanged. `PUBLICATION.json` attached to the release maps the original and public artifact hashes. This extra repository notice identifies publication provenance; the public repository commit is distinct from the original private development-history commit.

The tested APK and API are unchanged. Photo import and single-symbol handwriting remain experimental and require review. This is a historical preview, not final Version 2.0. Later versions are published in sequence, one per day when ready. The original CI workflow is preserved; this publication commit skips redundant automatic builds and makes no claim of a new GitHub CI pass.
